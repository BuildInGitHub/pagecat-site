# 页猫 PageCat — 官网

浏览器扩展「页猫」的落地页与隐私政策（中英双语）。

- `index.html` 中文落地页
- `privacy.html` 中文隐私政策（商店提交时填写此 URL）
- `en/index.html` English landing page
- `en/privacy.html` English privacy policy

在线地址：https://buildingithub.github.io/pagecat-site/

上架通过后，把中英两个 `index.html` 中 `btn-chrome` 按钮的 `href` 替换为真实商店链接。
