三件事，一件不打扰

没有弹窗广告，没有新标签页劫持，只有你需要时的那一下。

划词翻译

选中即译，译文贴着原文出现。默认走公共翻译接口，开箱即用；也可切换成你的 AI 接口获得更自然的译文。

AI 网页摘要

一键把长文压成三句话和关键词，Ctrl+Shift+Y 呼出侧边栏。接 DeepSeek / GLM 等 OpenAI 兼容接口，按你自己的 Key 计费。

桌宠提醒

一只会眨眼、能拖到九宫格任意角落的小猫，定时冒泡提醒你喝水休息。嫌它吵？气泡文案在设置里随便改。

隐私优先的设计

页猫没有自己的服务器：设置和 API Key 只存在你浏览器本地；划词与摘要内容仅在你触发功能时直连你配置的接口。详见 隐私政策。
