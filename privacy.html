隐私政策

最后更新：2026-09-17 · 适用于「页猫 PageCat」浏览器扩展

我们重视你的隐私。本政策说明页猫收集什么、不收集什么，以及数据如何流动。核心结论：页猫没有自己的服务器，不收集、不存储、不出售任何用户数据。

1. 页猫收集哪些数据

不收集。页猫不含账号系统、不含统计埋点、不含广告 SDK，因此不存在由我们运营的数据收集。

2. 数据如何流动

以下数据仅在你主动触发对应功能时产生，并直连发送至你配置的服务，页猫不经手、不留存：

  • 划词翻译：你选中的文本会发送到翻译接口（默认为公共翻译服务 Google Translate / MyMemory，可在设置中更换）。
  • 网页摘要 / AI 对话：当前页面的正文文本会发送到你自己填写的 AI 接口（如 DeepSeek、智谱 GLM 等 OpenAI 兼容服务）。使用哪家、发给谁，完全由你的配置决定。

这些请求从你的浏览器直接发往对应服务商，受该服务商自己的隐私政策约束。

3. 本地存储

以下信息保存在浏览器本地 chrome.storage.local 中，仅用于功能运行，不会上传：

  • 功能开关与偏好（目标语言、触发方式、桌宠尺寸等）
  • 你填写的 AI 接口地址与 API Key（仅存本地，请勿在公用电脑上填写）
  • 桌宠停靠位置等界面状态

卸载扩展即删除全部本地数据。

4. 浏览器权限用途

权限用途
storage在本地保存你的设置
activeTab / scripting在你划词或点击摘要时，读取当前标签页内容以完成翻译/摘要
contextMenus提供右键菜单快捷入口
sidePanel在浏览器侧边栏展示网页摘要
网络访问（http/https）连接你配置的 AI 接口与翻译接口；AI 地址由用户自定义，因此不能预限定域名

5. 第三方服务

翻译与 AI 能力由第三方服务商提供（Google、MyMemory、DeepSeek、智谱等，以你实际配置为准）。这些服务商可能按其自身政策处理请求内容，请参阅对应服务商的隐私政策。

6. 数据出售与广告

页猫不出售任何数据，不投放广告，不进行用户行为追踪。

7. 儿童隐私

页猫不面向 13 岁以下儿童，也不 knowingly 收集任何儿童的个人信息。

8. 政策变更

如本政策有实质变更，我们会更新页面顶部的日期，并在扩展更新说明中提示。

9. 联系我们

通过 GitHub 仓库 BuildInGitHub 的 Issues 联系。

Privacy Summary (English)

PageCat is a browser extension with no servers of its own. It collects, stores, and sells no user data — no accounts, no analytics, no ads. When you trigger a feature, selected text or page content is sent directly from your browser to the translation service (default: Google Translate / MyMemory) or to the AI endpoint you configure (e.g. DeepSeek, Zhipu GLM). Your settings and API key are stored only in local browser storage (chrome.storage.local) and are removed when you uninstall the extension. Browser permissions are used solely for the features described above. Contact: GitHub Issues.
